Privacy Policy

Last updated: 2026-10-08

This policy covers the personal Hermes Agent installation described on the homepage, operated by Nick Mordwinkin for his own, exclusive personal use.

Google data accessed

This integration requests the following Google OAuth scopes against the account owner's own Google account only:

  • gmail.readonly, gmail.send, gmail.modify — read, send, and organize email in the owner's own inbox.
  • calendar — read and manage events on the owner's own calendar.
  • drive — read, create, and organize files in the owner's own Google Drive.
  • spreadsheets, documents — read and edit the owner's own Sheets and Docs.
  • contacts.readonly — read the owner's own contacts for lookup purposes.

How this data is used

Google data is used exclusively to act as a personal productivity assistant for the account owner: summarizing email, drafting replies at the owner's direction, managing the owner's own calendar, and reading/writing the owner's own documents. It is never used for advertising, profiling, or any purpose unrelated to serving the account owner directly.

How this data is stored

OAuth tokens are stored locally on hardware owned and controlled by the account owner, encrypted at the filesystem level via standard OS file permissions. No Google data is transmitted to or stored by any third party. No Google data is sold, rented, or shared with any other individual or organization.

Data retention and deletion

Data is retained only as long as needed for the assistant to operate and is deleted immediately upon the account owner's request, or automatically when the OAuth grant is revoked. The account owner may revoke access at any time via Google Account → Security → Third-party apps & services, which immediately invalidates all stored tokens.

Google API Services User Data Policy

This application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions about this policy can be directed to the account owner via the contact information on the associated Google Cloud project.
